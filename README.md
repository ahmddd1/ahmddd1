## Highlighted Projects

**[DetectionForge](https://github.com/ahmddd1/DetectionForge)**
A detection engineering lab mapping MITRE ATT&CK techniques to Windows/Sysmon
telemetry and Splunk SPL detections. Covers PowerShell abuse, scheduled task
persistence, C2 beaconing, registry persistence, and LSASS credential
dumping — with three documented, root-caused detection gaps found in a
real Sysmon deployment, and a live Splunk dashboard tracking coverage.

**[Email Phishing Analyzer](https://github.com/ahmddd1/email-phishing-analyzer)**
SOC-grade phishing analysis tool: fetches emails via IMAP, performs header
analysis (SPF/DKIM/DMARC), extracts and checks URLs, analyzes attachments
(hash, type, YARA rules), detects phishing patterns in HTML content,
integrates VirusTotal, and generates automated PDF/HTML reports through a
web dashboard.

**Malware Analysis Lab**
Static and dynamic malware analysis with IOC extraction.

**Sysmon Detection Project**
Custom Sysmon rules, threat hunting queries, and Sigma rule mappings for
real-world detection use cases.

**SIEM Engineering Lab**
Splunk dashboards, alerting logic, and custom correlation searches.
